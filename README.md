# PyPracticeArena

A personal Python practice roadmap for building a daily coding habit and
progressing from the basics to advanced topics. Work through the folders in
order, write code every day, and use the project folder to put what you learn
into practice.

## How to use this repository

The numbered Python files are practice spaces. Add your own examples, exercises,
and solutions as you learn each topic; this repository does not provide
pre-written lessons or answers.

For each topic:

1. Learn one small concept at a time.
2. Type a short example yourself instead of only copying it.
3. Change the example and predict what will happen before running it.
4. Solve a small problem without looking at your earlier code.
5. Write down what you learned and what you want to review.

## A simple daily routine

Aim for 30–60 minutes, or choose a shorter session you can keep doing
consistently:

- **Review (5 minutes):** revisit yesterday's code or notes.
- **Learn (10–15 minutes):** choose one new concept from the current folder.
- **Code (15–30 minutes):** write examples and solve a small exercise.
- **Reflect (5 minutes):** note what worked, what was confusing, and what to try
  next.

If you miss a day, pick up where you left off. Understanding and regular
practice matter more than rushing through every topic.

## Learning path

| Step | Folder | Focus |
| --- | --- | --- |
| 1 | `01_basics/` | Setup, variables, data types, input/output, operators, conditions, loops, and strings |
| 2 | `02_data_structures/` | Lists, tuples, sets, dictionaries, nested data, and comprehensions |
| 3 | `03_functions/` | Functions, arguments, return values, lambdas, recursion, scope, and closures |
| 4 | `04_file_and_error_handling/` | Files, CSV/JSON, paths, and exceptions |
| 5 | `05_oop/` | Classes, objects, methods, inheritance, and object-oriented design |
| 6 | `06_intermediate/` | Modules, the standard library, regular expressions, logging, and environments |
| 7 | `07_advanced/` | Decorators, iterators, generators, typing, concurrency, and testing |
| 8 | `08_best_practices/` | Clean code, documentation, debugging, optimization, and design patterns |
| 9 | `09_projects/` | Practice by building small applications and combining what you have learned |

Move on when you can explain the current concept in your own words and use it
without simply copying an example. Revisit earlier topics whenever a project
shows you a gap.

## Getting started

Install Python 3.10 or newer. The practice files use Python's standard library;
there are no required third-party packages. Some topics or projects may need
optional packages, which can be added to `requirements.txt`.

Run a practice file from the repository root:

```bash
python3 01_basics/01_introduction_and_setup.py
```

On Windows, use `python` if `python3` is not available:

```bash
python 01_basics/01_introduction_and_setup.py
```

## Keep your progress visible

- Work on one topic at a time and keep your practice code in the matching file.
- Give project files a genuine attempt before looking up a complete solution.
- Revisit and improve earlier code as you learn better techniques.
- Celebrate consistency: a small program written today is progress.
